# 1. 데이터 불러오기 및 결측치 처리

- pd.read_csv()로 데이터를 로드한 후 info()와 df.isnull().sum() 및 df.isnull().mean()을 활용하여 컬럼별 결측치 개수와 비율을 진단

- 결측 비율이 56.8%로 기준치(50%)를 초과한 '메모' 컬럼을 자동 감지하여 데이터프레임에서 삭제.

- 결측치가 존재하는 나머지 수치형 변수(나이, 리뷰점수)는 각 열의 평균값으로 대체했습니다.범주형 변수(성별, 가입경로)의 결측치는 각 열의 최빈값으로 대체.

- 전처리 완료 후 df.isnull().sum()을 재호출하여 모든 결측치가 0으로 제거되었음을 검증.


# 2. 이상치 탐지 및 처리

- 연속형 변수 중 리뷰점수를 선택하여 boxplot을 통해 시각화하고 이상치 분포를 직관적으로 파악.

- IQR 기법을 이용하여 하한 경계값(2.35)과 상한 경계값(5.15)을 계산.

- 계산된 경계값을 기준으로 하한선이하의 리뷰점수는 2.35로 만점인 5점 이상의 리뷰점수는 5점으로 대체.
 
- 판단 근거:
  **하한치 이하의 데이터를 제거할 경우 고객들의 불만이나 이탈을 분석하지 못하고 상한치 이상의 값을 제거하게 될 경우 만점인 5점 리뷰들도 삭제되기 때문에 경계값을 기준으로 변경**




# 3. 범주형 변수 인코딩

- 처리 과정 요약범주형 변수의 도메인 성격에 따라 순서(서열)의 유무를 명확히 분류.

- 순서의 의미가 있는 변수인 멤버십등급은 LabelEncoder를 활용해 레이블 인코딩을 적용.

- 순서의 의미가 없는 변수인 거주지역, 성별, 가입경로, 쿠폰사용여부는 pd.get_dummies(drop_first=True)를 활용해 원-핫 인코딩을 적용.

- 인코딩 전/후의 데이터프레임 구조 변화를 직관적으로 비교하기 위해 shape와 columns를 비교하여 콘솔에 출력.

- 판단근거 : (**등급의 가치가 있는 멤버십 등급은 순서형 인코딩인 레이블을 사용하였고 서열없이 단순한 종류인 변수들은 인-핫 인코딩을 사용.)


# 4. 파생변수 생성 및 스케일링
- 기존 컬럼인 월평균구매금액과 구매횟수를 조합하여 고객의 1회당 지출 성향을 나타내는 파생변수 Buy = 월평균구매금액 / 구매횟수를 새롭게 생성했습니다.수치형 변수들 간의 거대한 단위 차이를 해결하기 위해 StandardScaler를 선택하여 표준화를 적용.

- 스케일링 전과 후의 describe().loc[['mean', 'std']] 기술통계량을 비교 출력하여, 모든 수치형 변수의 기준점(평균)이 0.000으로 중심 이동하고 표준편차가 1.001로 통일되었음을 입증.

- 모든 전처리가 완료된 데이터프레임을 df.to_csv('prj_data_cleaned.csv', index=False) 코드를 통해 안전하게 최종 산출물로 저장.
