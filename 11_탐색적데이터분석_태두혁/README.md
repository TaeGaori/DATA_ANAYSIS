# 1. 데이터 기초 특성 파악

- 분석 과정 요약pd.read_csv()를 사용하여 데이터를 로드하고 shape, dtypes, describe()를 통해 데이터의 기본 규격과 기술통계량을 진단.

- 데이터 타입을 기준으로 연속형 수치 데이터와 문자열 범주형 데이터를 자동 분류하여 리스트로 정리.

- 수치형 변수와 범주형 변수를 리스트 형태로 구분하고 범주형 변수 중 거주지역을 선택하여 value_counts()로 범주별 절대 빈도를 확인했습니다


# 2. 단변량/분포 시각화
- 수치형 변수(나이)의 분포 형태를 직관적으로 파악하기 위해 sns.histplot()을 활용하여 히스토그램을 시각화.

- 범주형 변수 중 거주지역를 확인하기 위해 sns.countplot()을 사용하여 범주별 막대그래프를 생성.

# 3. 상관관계 및 이변량 분석
- 수치형 변수 간의 선형적 연관성을 규명하기 위해 corr(numeric_only=True) 행렬을 계산하고 sns.heatmap(annot=True)으로 상관관계의 강도를 시각화.

- 상관계수가 가장 높게 나타난 [구매횟수 vs 월평균구매금액] 쌍을 선택하여 sns.scatterplot() 및 sns.regplot()으로 추세선이 포함된 산점도를 시각화.

- 범주형 변수(멤버십등급)와 수치형 변수(월평균구매금액) 간의 관계를 sns.boxplot()으로 시각화하여 등급별 구매력 편차를 추적.


# 4. 그룹별 비교 분석 및 인사이트 추출
- 특정 범주형 변수를 기준으로 groupby()적용하여 쿠폰사용여부에 따라 사용한 월평균구매금액의 평균을 나타냄

- 쿠폰사용여부에 따른 그룹화된 통계 테이블 데이터를 바탕으로 다중 막대그래프를 생성하여 비즈니스 성과 지표를 시각적으로 직관화.
